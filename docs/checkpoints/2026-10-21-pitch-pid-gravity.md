# Pitch 双环 PID + 重力补偿阶段存档

日期：2026-10-21。固定标签：`archive/pitch-pid-gravity-ki6000-20261021`。

这版作为下一轮真实视觉测试的对照：Pitch 使用位置环、速度环、速度环积分和随角度变化的重力前馈，尚未加入专门的 Pitch 摩擦补偿项。后续加入摩擦补偿时，保留此标签作为比较和回退点。

## 固定参数

| 参数 | 上电默认值 | 作用 |
|---|---:|---|
| 位置环 Kp / Ki / Kd | 0.015 / 0 / 0.01 | 角度误差转换为速度目标 |
| 速度环 Kp / Ki / Kd | 4000000 / 6000 / 1000 | 速度误差转换为驱动输出 |
| 重力 Gain | 2500 | 补偿幅值，控制量刻度 |
| 重力 Offset | 1.16 rad | 约66.46°；网页填写的是度 |
| 重力输出限幅 | ±5000 | 重力项自身的限幅 |
| 重力变化速度 | 20000/秒 | 限制补偿突变 |
| 合成输出限幅 | ±24000 | PID与重力项相加后的限幅 |
| 积分输出限幅 | ±3000 | 限制速度环 I 项 |
| 积分分离阈值 | 0.1 rad | 约5.73°；超过时暂停积分、保留已有 I 项 |

重力前馈公式为 `2500 * cos(实际Pitch角度 + 1.16)`，角度使用 rad。INS Pitch 正数对应抬枪。电机指令在合成输出末端沿用原方向转换。

本次存档把源码默认 Ki 从5000对齐到实测的6000。串口只改 RAM，复位后恢复上述默认值；实际测试时仍以网页板端读回值为准。

## 包含的调试功能

- UART1外壳三针口对应 USART6，可通过本地网页调参和模拟 Pitch 绝对目标。
- Gain、Offset、Ki均可读写并确认，参数批次任一项非法则整批拒绝。
- Ki串口范围0～8000；改为非零保留已有 I 输出，设为0同时清零 I 项。
- 连接设备只读，不自动改参数、使能或切换来源。旧固件可读原参数，但Ki写入区会提示需要更新固件。
- CSV包含实际 Ki、I输出、角度和限幅标志；每次开始新记录会清空上一轮连续记录缓冲。
- 退出自瞄或遥控掉线后恢复 CAN 来源；网页断开会尝试恢复 CAN。只关闭网页或拔 USB 不会撤销最后目标。

日常使用见 [SERIAL_TUNING.md](../../SERIAL_TUNING.md)。[BASELINE.md](../../BASELINE.md) 记录最初恢复的无VOFA版本，不是本阶段参数说明。

## 实测记录和已支持的结论

两份用户提供的原始 CSV 原样保存，未裁剪或修改字段：

- [Ki=0，手瞄与自瞄阶梯](../../tests/recordings/2026-10-21/pitch-ki0.csv)：原文件 `gimbal-recording积分常量为0后手瞄+自瞄步进阶梯测试.csv`，362条、约81秒。
- [Ki=6000，手瞄与自瞄混合](../../tests/recordings/2026-10-21/pitch-ki6000.csv)：原文件 `gimbal-recording积分常量变为6000后手瞄自瞄混合测试数据.csv`，495条、约112秒。

两份记录的 Gain=2500、Offset=1.16 rad相同。Ki=0记录的 I 输出始终为0；Ki=6000记录的 I 输出参与纠偏。

选自瞄中相同的 `+9° → +8° → +7° → +6° → +5°` 下降路径，比较下发后约1.5秒的误差（目标减实际）：

| 目标 | Ki=0误差 | Ki=6000误差 | 两份CSV的数据行 |
|---|---:|---:|---|
| +8° | -1.619° | +0.101° | 220 / 285 |
| +7° | -1.356° | -0.019° | 229 / 297 |
| +6° | -1.301° | -0.041° | 237 / 311 |
| +5° | -1.213° | +0.087° | 246 / 322 |

行号包含首行表头。对应实际等待时间均在1.48～1.51秒之间。两份记录均未捕捉到 PID或总输出限幅。Ki=6000的部分长停留段末段误差约0.05～0.06°，但短阶梯仍有残差和收敛时间。

这些结果支持6000在本次条件下有效，不证明它是最优增益，也不证明重力模型、固定摩擦估计或所有工况已经验证。手瞄路径不相同，不将手瞄整段均值用于严格对照。
