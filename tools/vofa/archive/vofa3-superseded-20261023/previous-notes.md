# 用实测目标调Yaw

这次提供独立的“实测视觉Yaw重放”控件。保留原来的正弦控件，用本次记录中的不规则目标做跟踪调参。无需修改或重新烧录固件。

## 这份记录里有什么

原件为 `vofa+3_31023-40329.csv`，9307行、12通道，没有时间戳。读取的是第四列 **Yaw目标角（°）**，不是实际角，也不是末尾的门控误差。末尾门控为0的行不删除。

记录混有不同阶段：前段有不规则目标台阶和突跳，后段多次出现规则正弦。实际角的相邻差值与上传速度交叉计算：前段每行约20.7 ms，后面主要运动段约5.0～5.2 ms。不能把整份CSV按单一周期直接播放。

默认提取**数据行346～2005**（不含表头，首尾都保留），共1660点。主要指标：

| 项目 | 数值 |
| --- | ---: |
| 估计采样周期 | 20 ms，可在控件里调整 |
| 估计时长 | 33.20 s |
| 原Yaw目标范围 | −16.875517～1.186560° |
| 记录中的目标变化次数 | 551 |
| 最大单次目标跳变 | 8.976105° |
| CAN在线标志为0的采样 | 139点 |
| Yaw门控阈值为0的采样 | 138点 |

后两项是原始观测，重放不恢复CAN断线或开火状态。仅凭这些列不能判定每次开火是否真实出弹。

## 安装和开始

1. 保存当前VOFA采样，遥控退出自瞄，断开串口。
2. 双击本目录的 `install_replay.cmd`，或运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/vofa/install_replay.ps1`。脚本只复制重放控件，不关软件、不发送命令、不覆盖原正弦控件。
3. 手动重启VOFA，在控件栏刷新后拖入 **实测视觉Yaw重放**。
4. 控件背景右键 → 绑定数据 → **I2：Yaw实际角**。I2显示增益1、偏置0。
5. 串口使用现有115200、8N1、JustFloat，等待遥测更新，再按原流程进入自瞄。
6. 第一轮可用“完整视觉活动段”、**幅度比例0.5**、**记录采样周期20 ms**。起点相对变化约−4.83～+4.20°，最大相邻发送跳变约4.55°。
7. 点“开始重放”，观察I3目标角与I2实际角。每轮对比保持片段、比例、周期和初始姿态一致，只改一个控制参数。
8. 到时自动结束，也可点“停止发送”。停止保持最后目标，不自动回中。结束后遥控退出自瞄，再恢复CAN来源。

也提供“密集跳变段”（数据行535～1034，约10 s）和“后段跟踪”（1701～2005，约6.10 s），方便多轮重复调参。

## 目标如何生成

```text
指令Yaw = 本轮开始时的实际Yaw + 幅度比例 × (记录Yaw − 所选片段首个Yaw)
```

比例1保留原角度变化，只平移起点；比例0.5等比例减半。超过±180°时按原角度协议回绕。不平滑，不拟合正弦，不补造随机噪声。Pitch保持已有目标。开始重放不会修改前馈增益，按调试器中的当前值运行。

控件每42 ms请求发送一次 `yaw:角度`，按当时进度取最近已到达的记录采样值，保持到下一次发送。按20 ms记录周期计算，551次记录变化重采样后约510次；短于发送周期的中间点可能被略过，最大相邻发送跳变约9.108°（比例1）。这是一份**实测轨迹的约24 Hz模拟**，不是原始CAN逐帧重放。QML定时器和串口队列也会产生抖动。

开始只发送一次来源切换请求，随后只发Yaw目标，沿用固件已有的串口模拟路径。该路径的fire字节为0，禁止模拟开火。前馈启用时，固件会根据相邻串口帧重新估计目标速度。4 Hz等板端正弦的解析速度不用于这次重放。

CSV缺少原始帧时间、fire/rev和插值开关记录；采样周期是交叉估计值。如果录制时开启了插值，CSV记录的是插值后的控制目标，无法据此恢复原始视觉指令。重放也不包含实际发射产生的机械扰动，因此重复轨迹调好后仍需真实视觉和打弹验证。

重放请求 `stream:20`。串口目标命令还会产生额外遥测回帧，后续导出CSV仍不带精确时间戳；普通Δt时间轴只用于近似观察，不能直接据此计算精确延迟。

## 更换后续实测片段

运行：

```powershell
python -X utf8 tools/prepare_vision_replay.py "新记录.csv" --first 346 --last 2005 --sample-ms 20
```

数据行需要按新记录重新选取；默认346～2005只对应本次记录。工具生成 `vision_replay/recording.js` 和分析JSON，保留原CSV不变。重新运行安装脚本、重启VOFA后生效。
