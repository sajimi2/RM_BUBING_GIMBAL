# 双轴实录重播与种子模拟

源码控件提供三种模式：本次双轴实录、双轴种子模拟、上次Yaw基准。新增的 `aim:Pitch角,Yaw角` 命令把两轴放进同一个视觉控制帧，单位为度。例如 `aim:-2,20` 表示Pitch −2°、Yaw 20°。原 `yaw`、`target` 命令继续保留。

本次仅扩展串口模拟入口、数据准备及电脑端控件，不修改PID、前馈增益、插值、滤波或开火参数。随机计算在VOFA电脑端完成，C板只接收目标。串口载荷沿用原视觉格式，fire/rev均为0；固件仍执行遥控在线、自瞄模式、来源和Pitch限位检查。

## 当前运行中的程序

修改源码和离线编译不会改变已经烧录的固件，也不会更新正在运行的VOFA控件。本轮没有连接串口、安装控件或烧录。

等当前记录结束后再更新：

1. 保存CSV，遥控退出自瞄，断开VOFA串口。
2. 编译并烧录支持 `aim` 的当前固件。烧录会中断程序并复位板子。
3. 运行 `tools/vofa/install_replay.cmd` 更新控件，再手动重启VOFA。安装脚本会备份旧文件，不重启软件、不发送命令，不修改原正弦控件。
4. 拖入重播控件，背景右键分别进入“Yaw实际角（I2）”和“Pitch实际角（I0）”，各自绑定对应通道，增益1、偏置0。
5. 使用115200、8N1、JustFloat，等待新遥测，再按原流程进入自瞄。正常重播保留VOFA总发送为1、附加诊断为0。

双轴模式需要新固件和新控件配套；旧固件不能识别 `aim`。旧Yaw模式仍发送原来的 `yaw`，不修改Pitch目标。

## 三种模式

| 模式 | 用途 | 输入 |
| --- | --- | --- |
| 本次双轴实录 | 固定输入比较参数；完整保留两轴台阶、保持和突跳 | 本次CSV的I1/I3 |
| 双轴种子模拟 | 同类指令的不同轨迹；可固定种子反复对照 | 本次成对短片段＋上次Yaw形状 |
| 上次Yaw基准 | 保留原来的零前馈/Kp=0.012录制基准 | 原2624点Yaw，不重播Pitch |

首次默认两轴幅度比例均为0.5。单轴比例设为0可以保持该轴起点，两轴不能同时为0。实录按所选片段首点对齐到当前实际角；Yaw先按最短角差展开再回绕，Pitch不回绕。发送前检查整段Pitch范围，越限会拒绝启动，不能用硬裁切把超限轨迹改形。

默认选本次的“普通跟踪（训练段）”。也可选“独立留出段”或“完整实录（含切入大跳变）”。完整实录保留第66行约7.5°的Pitch切入变化，以及前后保持；普通片段从第66行开始，起点重置后不包含这一切入步阶。

控件每42 ms发送一次目标，双轴模式一次只发一条 `aim`。到时保持最后目标，不自动循环、不回中、不恢复CAN。断连、遥测过期500 ms、界面卡顿超过200 ms或时钟回退时停止发送，不成串补发过期点。载入布局和打开软件不会自动开始。

## 种子与复现

- 不勾选“每轮自动换种子”：填写0～4294967295的整数。同样的模型版本、数据、种子及设置生成同样的偏移轨迹。
- 勾选：每轮开始时选一个新种子，并回填到输入框。取消勾选后可直接重跑刚才的轨迹。
- “本轮配置”可选中复制，包含模式、实际种子、幅度、时间设置、起始姿态、数据哈希和轨迹标识；布局保存也保留这项信息。
- 轨迹标识是便于对照的滚动校验值，不是安全哈希。实际串口时序仍会受电脑调度影响；种子保证生成目标一致，不保证物理执行时间逐微秒一致。

默认模拟30秒，最大相对偏移Yaw ±12°、Pitch ±3°；这些是电脑端轨迹范围，不是PID参数。范围太小且无法拼接时明确拒绝，需减小幅度比例或增大允许偏移。

## 模拟怎样保留真实特性

模型 `dual-block-v1` 先按估计记录周期、42 ms发送周期作零阶保持取样，再抽取连续短片段：

1. 七成候选使用本次成对Yaw/Pitch片段，保留局部保持、反转及两轴关系。
2. 三成候选使用上次Yaw形状，配本次Pitch连续变化序列，并让Pitch共用Yaw更新时刻。上次没有Pitch原列，此分支不冒充旧记录的真实双轴配对。
3. 常规块长12～36个发送点，Yaw局部幅度扰动±10%、Pitch ±15%、时间伸缩±10%。接缝使用片段前一采样到首采样的真实增量，不额外插入零步长。
4. 整块越过相对偏移范围时尝试镜像或重抽；靠近范围边缘时允许短块。不逐点硬裁切，不向板端增加随机或统计任务。

块边界、幅度扰动和重抽会改变部分统计；这是同类输入的压力测试，不是完整目标运动或视觉识别的物理模型。调整控制参数后，模拟不会像真实视觉一样根据新云台响应重新预测目标。

## 离线验证

宿主测试覆盖全部2140对新目标、原2624点Yaw、双轴提交及任一轴无效时整帧拒绝、遥控/来源限制、固定与自动种子、100个种子的范围检查、Pitch整段预检、三种模式按钮和Timer、停止及不自动启动。

还会把留出区间全部替换成无效数，在内存副本上证明生成结果不变。20个种子（0～19）、每个30秒、幅度比例1，按同样42 ms取样与整段留出数据比较变化幅度、保持比例、方向反转及双轴共同更新。结果写入 `build/host-vision-simulation-validation.json`。这些统计检查不证明所有工况都已泛化，也不证明实车控制效果。

安装脚本只在临时假VOFA目录做过打包、备份和文件一致性测试。控件按钮/Timer逻辑离线执行通过；当前VOFA内部实际加载、菜单绑定和实车重播仍需在结束记录后验收。
