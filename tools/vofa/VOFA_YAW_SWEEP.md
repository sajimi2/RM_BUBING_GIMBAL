# Yaw连续目标与CSV截取

## 先完成一次安装

需要先编译、烧录支持 `yaw` 命令的这版固件。只复制控件不会让旧固件支持新命令。

控件源码在 `yaw_sweep/`。本机安装脚本 `install_widget.ps1` 会从正在运行的VOFA进程查到安装目录，把控件复制到它的 `plugins/widgets/yaw_sweep/`，不会关闭软件、连接串口或发送命令。

退出自瞄、保存当前CSV、断开串口后，手动重启VOFA。打开左侧控件栏，从列表拖入 **Yaw小幅连续摆动**（外观上有“开始摆动”“停止发送”按钮）。若没有看到新控件，点控件栏刷新按钮。

## 点按钮做一次实验

1. 连接串口，确认新鲜的8通道遥测在更新。
2. 在新控件背景上右键 → 绑定数据 → 选择 **I2：Yaw实际角**。I2显示增益保持1、偏置0。
3. 遥控器拨到自瞄。控件不能代替遥控器使能。
4. 第一轮保留默认值：**幅度±3°、摆动频率0.5 Hz、时长10秒**。
5. 点“开始摆动”。程序把此刻I2作为中心，约每42 ms发一次 `yaw:角度`，约23.8 Hz。摆动曲线是正弦，0.5 Hz表示每2秒一轮左右往返，并非每秒只发半次指令。
6. 看I3目标角是否按中心±3°变化，I2是否跟随。控件显示“已发送”不代表固件接受；没进自瞄或旧固件都会导致命令不生效。
7. 到时自动停止，也可点“停止发送”。停止只停止新增目标，保持最后一个目标，不自动回中、恢复CAN或退出自瞄。
8. 结束后先遥控退出自瞄，再发 `source:0` 恢复真实视觉来源。

控件只在点击开始时发一次 `source:1`，不会持续重新接管。遥控退出后，固件恢复CAN来源，后续串口Yaw指令会被拒绝。停止上传或通信超过0.5秒没有新遥测，控件也会停止发送。重新打开软件、载入布局、拖入控件都不会自动开始摆动。

支持幅度0～10°（不含0）、摆动频率0.1～2 Hz、时长1～60秒。改变频率会改变要求的峰值转速；先保持幅度和频率不变比较两轮曲线。此测试没有模拟视觉噪声、预测或丢帧。

## 原有滑条和按钮也可以用

`pitch-commands.json` 已增加“模拟Yaw目标（度）”命令，格式 `yaw:%f\n`。载入命令表后，滑条右键绑定这个命令、数据绑定I3，就能直接输入Yaw绝对角度。Pitch命令仍是 `target:%f\n`，数据绑定I1。

`yaw` 修改Yaw时保留Pitch目标；`target` 修改Pitch时保留Yaw目标。串口载荷仍是原视觉的8字节格式，不允许开火标志。真实CAN控制和PID参数未改。

## CSV不用再手动删五万行

双击 **open_csv_trim.cmd**，打开“VOFA CSV截取”窗口，无需安装第三方Python库，也不占用串口。

1. 点“打开CSV”，选择VOFA导出的文件。支持UTF-8和常见的GBK/GB18030中文表头。
2. 默认预览Yaw实际角、目标角；上方可换成其他列。
3. 在图上左右拖动选出本轮实验，也可直接输入“开始数据行”“结束数据行”。行号从1开始，不含表头，首尾两行都保留。
4. “最后10秒”按输入周期估算最后多少行；它只是快捷选择。需要精确选一轮时，以目标曲线的位置和行号为准。
5. 点“另存选中范围”，得到新CSV。原文件不会被覆盖。

工具只裁剪区间，保留所有列及原始数值，不删除零值、不平滑、不排序。图上为了速度会抽点预览，导出不会抽点。含旧通道格式或无效数据的区间仍需人工避开，工具不会猜测并修改它们。

当前遥测默认20 ms，但下行命令还会额外返回遥测，自动摆动期间行间隔可能不均匀。因此窗口里的秒数是估算，不是硬件时间戳；这版没有为时间戳增加第9个通道。若做精确延迟分析，需要把这个限制告知分析者。

录下一轮前，也可以在VOFA里先保存本轮，再点击采样区左下角垃圾桶清除旧采样；这不会改变云台控制目标。

## 验证范围

宿主测试覆盖双轴目标保持、连续绝对目标不累加、模式限制、禁止串口开火、8通道编码，以及CSV首尾边界/编码/原件保护和运动公式。Tk截取窗口已做离线启动检查；VOFA内部实际加载新QML控件、24 Hz实测抖动和实车跟随需要现场验证。

控件使用[VOFA官方插件接口](https://www.vofa.plus/docs/learning/widgets/development/)，只调用公开的发送和数据绑定接口。
